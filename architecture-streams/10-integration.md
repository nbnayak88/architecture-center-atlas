# 10. Integration Architect (IA)

## WHAT

Designs system interoperability using APIs, events, message queues, middleware, and enterprise integration patterns (EIP).

## WHY

Connected architecture ensures systems communicate seamlessly, eliminating silos and enabling real-time business.

## HOW

- Define API strategy, event-driven architecture
- Implement middleware, iPaaS, and EDI frameworks
- Govern security, SLAs, orchestration, and routing
- Ensure multi-system workflows work end-to-end
