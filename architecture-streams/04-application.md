# 4. Application Architect (APA)

## WHAT

Designs the application landscape, solution components, modular systems, application responsibilities, and lifecycle dependencies.

## WHY

To ensure business applications are scalable, interoperable, maintainable, and aligned with the enterprise architecture.

## HOW

- Define solution architecture and application boundaries
- Define application behavior, configuration dependencies, and integration specifications
- Ensure non-functional requirements (NFRs) are met
- Govern application lifecycle modernization

## Architecture-path boundary

Process Architect is a specialization under Business Architect. Application Architect uses business-process requirements as inputs while owning application structure, responsibilities, configuration, lifecycle behavior and application quality. See [Business Architect](02-business.md).
